# Letter RNG v2

Open `index.html` in a modern browser.

New:
- Local username/password account system
- No email or verification required
- Each browser stores its accounts with localStorage
- Points awarded according to badge rarity
- Slower 6-stage letter reveal for suspense
- Points, rolls, badges and history persist per account

Important:
This is a simple offline account system, not a secure online authentication system. Passwords are stored locally in the browser because the game has no server.
